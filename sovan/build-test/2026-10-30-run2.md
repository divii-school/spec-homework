# Build test — run 2 of the improvement round (2026-10-30, evening)

Spec under test: `sovan/spec.md` v1.3 (1,800 lines, commit 8c176b4, after the seven v1.3 commits).
Method: same as run 1 — a fresh AI session (Claude Code, Fable 5.1, general-purpose subagent) given only `spec.md`, asked to list every guess that would change what gets built (wording and style excluded this time, as in the official test). No other file read; the agent had not seen v1.2.

Result: **58 guesses — HIGH 11, MED 47, LOW not counted.** Run 1 on v1.2 had 55 HIGH + MED (83 with LOW). The surface gaps of v1.2 are gone (constants, ownership, admin, health, retention owner, event idempotency, grace, checkout expiry all reported as defined); the new list is deeper (job identity, write races, erasure storage, refund lookup) plus ten contradictions that v1.3 itself introduced (#4, #6, #24, #27, #32, #33, #38, #42, #43, #45). Target before Nov 4: fewer than 5.
