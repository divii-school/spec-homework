## Final report

Build test of `sachin/spec.md` (v1.0, all 3,337 lines read; no other file opened, nothing edited, no git).

I walked through building the whole system: the Flyway migrations V1–V3, all API endpoints from API-001 to API-022, the worker and sweeper, the AI call, the scheduled jobs, the Razorpay checkout, webhook, reconciliation and cancellation, the Next.js pages, local/dev/staging/prod configuration, Terraform, the CI/CD pipeline and observability. Almost every flow is specified down to check order, SQL, locks, status codes and per-environment values. Only 7 places would force a guess or contain a contradiction that changes what gets built. None of them is high impact, and all are cheap to fix.

**Ordered by impact, highest first:**

1. **GUESS — 2.2 page table vs FR-019 c8, FR-026 c3, the result page's "upgrade banner for FREE", and the history page's Pro filters and compare. Impact: medium.**
   - **What is missing:** three pages must know the reader's plan, but none of the APIs they call returns it.
     - `/analyses` calls API-008, API-001 and API-005.
     - `/analyses/[analysisId]` calls API-009, API-011 and API-010.
     - `/privacy` calls API-016, API-002, API-003 and API-013.
   - Without the plan, the builder must guess whether to show the Pro filters and compare boxes, the upgrade banner, and the "Your Resume Pro subscription ends now…" line in the delete dialog. Inferring it from `dimensions` or `hiddenSuggestionCount` fails in edge cases.
   - **Fix:** add API-012 (or API-019) to those three pages' calls, or add a `readerPlan` field to the API-008 and API-009 responses.

2. **GUESS — Section 5 intro, 5.6 and the V1 description. Impact: medium.**
   - **What is missing:** the section 5 intro says `ro_app` has SELECT, INSERT, UPDATE and DELETE "on these tables only". 5.6 step 6 grants explicitly on the V3 tables. But V1 is defined as "exactly as 5.2 and 5.3 show them", and nothing says who grants `ro_app` access to TBL-001 – TBL-015 (including `shedlock`).
   - If no grant exists, the API and worker fail with "permission denied".
   - **Fix:** state that V1 ends with `GRANT SELECT, INSERT, UPDATE, DELETE ON` TBL-001 – TBL-015 `TO ro_app` (the role already exists because the migrate step creates it before Flyway).

3. **GUESS — CR-009 / 2.2 `common/logging` "log redaction". Impact: low to medium.**
   - **What is missing:** CR-009 is "checked by a unit test on the log redaction filter", but the filter is never defined. It is unclear what it masks (the 4.6.1 patterns? JWT-shaped strings? cookie and Authorization values?), where it applies (message, MDC, exception text), or whether it masks or drops.
   - **Fix:** define the filter as a Logback converter or masker with an exact list of patterns and the replacement token.

4. **GUESS — NFR-003 / 4.8.7 `analysis_duration_seconds` (`analysis.duration`). Impact: low.**
   - **What is missing:** NFR-003 measures "QUEUED to COMPLETED" (from `created_at`), but TBL-014 `duration_ms` and API-015 measure `finished_at − started_at`. The histogram's start point, which statuses it observes, and which component records it are not stated, so the p95 ≤ 45 s figure depends on that choice.
   - **Fix:** define it as `finished_at − created_at`, observed by CMP-010 for `COMPLETED` only.

5. **GUESS — 4.4 `scripts/send-test-webhook.sh <event>`. Impact: low.**
   - **What is missing:** the script "posts the 4.3.9 example body for that event", but 4.3.9 has no example bodies. The only example in the spec is API-022's `subscription.charged`, so the bodies for `authenticated`, `activated`, `pending`, `halted`, `cancelled` and `completed` (and their `status` values) must be invented.
   - **Fix:** give one minimal body per event, or state that the script reuses the charged example with `event` and `status` replaced and the `payment` part removed.

6. **CONTRADICTION — FR-016 criterion 4 vs 3.4 "Texts in the PDF report". Impact: low.**
   - FR-016 criterion 4 says: "FREE reports end with one line saying how many suggestions are hidden".
   - 3.4 says the line appears "only when `hiddenSuggestionCount` > 0".
   - **Fix:** add "when `hiddenSuggestionCount` > 0" to FR-016 criterion 4.

7. **CONTRADICTION — NFR-009 / 7.2 vs 4.6.1. Impact: low (tests only).**
   - NFR-009 says "a fixed set of 50 sample contact formats", and 7.2 says "Redactor test set of 4.6.1 (50 samples)".
   - 4.6.1's "Test set for NFR-009" lists only 14 values (9 replaced, 5 not replaced).
   - **Fix:** list all 50 samples in 4.6.1, or change NFR-009 and 7.2 to "the 14 samples of 4.6.1".
